Posts are saved into the same website files as always. The public look of the site does not change.

1. GitHub token (once per computer)

This is a secret from GitHub that lets this page save files. Paste it here. It stays in this browser on this computer only — never in the website code.

  1. On GitHub, click your profile picture → Settings.
  2. At the very bottom of the left menu, click Developer settings.
  3. Click Personal access tokens, then create a token.
  4. Allow that token to read and write files in the lookgood repository.
  5. Copy the token, paste it below, and click Save.

2. Write a post
What kind of post?

Announcement = title, text, and a cover picture. Gallery = the same, plus photos. Galleries get a photo folder and the “Full gallery click here!” link. Announcements do not.

These are saved as full-size photos. The site’s usual thumbnail helper will make 320px thumbs after they are saved.
