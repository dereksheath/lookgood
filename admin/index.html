Private

Official posting page for lookgoodparty.com, the Look Good Party photo blog of 2000s dance nights at El Cid in Los Angeles. Visitors do not use this page.

New post

Posts are saved into the same website files as always. The public look of the site does not change.

1. GitHub token (once per computer)

This is a secret from GitHub that lets this page save files. It stays in this browser on this computer only — never in the website code. On GitHub: profile picture → Settings → Developer settings → Personal access tokens. Make a token that can edit the lookgood repository, then paste it here.

2. Write a post
What kind of post?

Announcement = title, text, and a cover picture. New gallery = the same, plus photos. If you have hundreds of pictures, publish a first batch, then use “Add photos to a gallery” for the rest.

Choose the gallery you already published. New pictures are added to that same folder; they do not replace the ones already there.

These are saved as full-size photos. The site’s usual thumbnail helper will make 320px thumbs after they are saved. About 50 to 100 photos at a time is a safe batch if a huge upload fails.

3. Guestbook

People sign at lookgoodparty.com/guestbook/. They only use this website — they never see GitHub. To turn signatures on, add a repository secret named GUESTBOOK_TOKEN (the guestbook token, not the admin token). In the lookgood repo: Settings → Secrets and variables → Actions → New repository secret. Spam or anything you do not want can be deleted here.
