This page is only for posting to the Dancefloor site.

New post

Posts are saved into the same website files as always. The public look of the site does not change.

1. GitHub token (once per computer)

This is a secret from GitHub that lets this page save files. It stays in this browser on this computer only — never in the website code. On GitHub: profile picture → Settings → Developer settings → Personal access tokens. Make a token that can edit the lookgood repository, then paste it here.

2. Write a post
What kind of post?

Announcement = title, text, and a cover picture. Gallery = the same, plus photos. Galleries get a photo folder and the “Full gallery click here!” link. Announcements do not.

These are saved as full-size photos. The site’s usual thumbnail helper will make 320px thumbs after they are saved.

3. Guestbook

People sign at lookgood.party/guestbook/. They only use this website — they never see GitHub. To turn signatures on, add a repository secret named GUESTBOOK_TOKEN (the guestbook token, not the admin token). In the lookgood repo: Settings → Secrets and variables → Actions → New repository secret. Spam or anything you do not want can be deleted here.
